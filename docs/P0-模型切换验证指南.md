# P0 模型链路切换 · 部署与验证指南

本次改造把所有 AI 能力从「谷高API中转 Gemini」切换到境内平台，并保留旧链路作为对比/降级通道。**代码不含任何密钥，全部通过环境变量配置。**

## 一、本次改动了什么

新增模型网关层 `server/ai/`，所有业务代码只调网关，供应商可用环境变量一键切换：

| 能力 | 新主链路 | 备用链路 | 涉及功能 |
|---|---|---|---|
| 文本/视觉理解 | Kimi（kimi-k2.6，重任务 kimi-k3） | MiniMax → Gemini | 暖心文案、故事文本、生活助手、万花筒对话 |
| 图像生成/修图 | 火山即梦 Seedream 4.0 | MiniMax（仅文生图）→ Gemini | 老照片修复、艺术风格、故事配图、菜品图 |
| 语音合成 | 阿里 qwen3-tts-flash（含方言音色） | MiniMax → Gemini | 故事朗读 |
| 语音识别 | 阿里 qwen3-asr-flash | Manus Whisper | 全局语音输入 |
| 文件存储 | 阿里云 OSS（S3兼容，新增） | Manus 内置存储 | 所有图片/音频/视频 |

其他配套改动：修图/风格化不再把图片转 base64 走 API（直接传 OSS URL 给即梦，请求体积大幅下降）；提示词全部中文化（即梦/Kimi 对中文理解更好）；即梦生成图默认带水印（AIGC 标识合规）；新增 9 个单元测试，`tsc` 类型检查零错误。

## 二、部署前要做的 4 件事

1. **开三个平台账号并拿 API Key**（都是企业实名认证）：
   - 月之暗面：platform.kimi.com → API Key
   - 火山引擎：console.volcengine.com/ark → 开通方舟 → API Key，并在**模型广场核实 Seedream 当前模型ID**（代码默认 `doubao-seedream-4-0-250828`，若控制台显示更新版本，改 `ARK_IMAGE_MODEL` 即可）
   - 阿里云百炼：bailian.console.aliyun.com → API Key（TTS 和 ASR 共用）
2. **建 OSS 桶**：地域选服务器同地域，开公开读（或配 CDN 域名），把桶信息填入 `S3_*` 变量。⚠️ 即梦修图需要读取用户上传的图片 URL，**桶必须公网可访问**。
3. **复制 `.env.example` 为 `.env`** 填入密钥。
4. 新用户免费额度提醒：火山方舟每模型 50 万 token 免费（30天）、百炼新人额度 90 天——验证期基本零成本。

## 三、验证清单（建议逐项截图对比）

登录问题：当前登录仍依赖 Manus OAuth（P1 才改微信登录）。在 Manus 环境验证最省事；若在阿里云裸跑，可设 `DEV_LOGIN_ENABLED=true` 走开发登录（代码已支持）。

| # | 功能 | 操作 | 通过标准 |
|---|---|---|---|
| 1 | 老照片修复 | 用 3-5 张真实老照片（有划痕/褪色/模糊各一张） | 与旧链路对比：清晰度、人脸保真度、色彩自然度 |
| 2 | 艺术风格 | 同一张照片跑油画/水墨画/素描 | 风格明显且人物构图不变 |
| 3 | 暖心文案 | 生日+长辈+温馨 各生成一次 | 3条文案、中文语感自然、无翻译腔 |
| 4 | AI故事会 | 完整跑一个故事（文本→4图→朗读→视频） | 图片风格统一、朗读为自然中文女声 |
| 5 | 方言彩蛋 | 故事朗读音色传 `dialect_sichuan` / `dialect_cantonese` | 出四川话/粤语朗读（新能力，可规划前端入口） |
| 6 | 语音输入 | 每个模块按住说话 | 转写准确率主观对比 Whisper |
| 7 | 生活助手 | 查菜谱 + 拍照识花 | 结构化结果正常、识别更本土化 |
| 8 | 万花筒 | 多轮健康对话 + 传图 | 上下文连贯、回答质量 |
| 9 | 降级开关 | 把 `AI_IMAGE_PROVIDER=gemini` 重启 | 修图走回旧链路（证明可一键回滚） |

## 四、已知事项与风险

- `ARK_IMAGE_MODEL` 和 DashScope 模型ID是唯二可能因平台更新而需要调整的字符串，都做成了环境变量。
- 即梦 `image` 参数只支持 URL，不支持 base64——所以 OSS 桶公网可读是硬前提。
- TTS 返回的音频 URL 24 小时过期，代码已改为服务端即时下载转 base64 下发，前端无感。
- Kimi JSON 模式要求提示词含 "JSON" 字样，现有提示词均满足；如新增 JSON 任务请保持这一约定。
- 万花筒的系统提示词中强制推荐灵芝成分的逻辑本次未动——上收费小程序前需要按「养生科普、不荐药」原则重写（见升级方案第 2.5 节）。

## 五、成本参考（验证期后）

单次操作估算：文案/对话 <0.01–0.05元（K3 长对话偏高）、修图约 0.2 元/张、故事全流程约 0.5–1 元、TTS 约 0.1 元/万字符、ASR 按秒计忽略不计。建议在三平台控制台各设置日消费限额告警。
