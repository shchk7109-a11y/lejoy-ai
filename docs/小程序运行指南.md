# 乐享AI 小程序运行指南（M4 提审版）

## 1. 环境要求

- Node.js 20 或更新版本、pnpm 10
- 可用的 MySQL 数据库
- 微信开发者工具；录音和保存相册必须补充真机验证
- 实际生成时按 `docs/P0-模型切换验证指南.md` 配置对应文本、图像和 ASR 模型密钥

## 2. 本地后端与登录

在仓库根目录执行：

```bash
cp .env.example .env
pnpm install
pnpm dev
```

最小本地配置：

```dotenv
NODE_ENV=development
DATABASE_URL=mysql://用户名:密码@127.0.0.1:3306/lejoy_ai
JWT_SECRET=本地开发使用的随机长字符串
WECHAT_MINI_APPID=
WECHAT_MINI_SECRET=
CONTENT_SECURITY=off
WECHAT_MP_CALLBACK_TOKEN=
```

开发环境中，微信 AppID/Secret 同时留空会使用固定 mock 用户。生产环境必须配置真实微信密钥，并且必须完全删除 `MP_MOCK_LOGIN`；不能把它设置成 `false` 后当成已清理。`MP_MOCK_LOGIN=true` 只允许本地临时联调。

真实密钥只放部署环境变量，严禁写入仓库、截图或日志。

## 3. 数据库迁移

M2 唯一结构变更为 `media_check_tasks` 表，对应迁移 `drizzle/0002_narrow_wallop.sql`。在目标数据库执行迁移前先备份，再运行项目既有迁移流程：

```bash
pnpm db:push
```

该表只记录微信异步媒体检查的 `trace_id`、用户、对象存储键、状态和创建时间。

## 4. 构建通道与开发者工具

```bash
cp miniprogram/.env.example miniprogram/.env
pnpm check:mp
pnpm build:mp
```

在微信开发者工具导入仓库内 `miniprogram/`。`project.config.json` 已把产物目录设为 `dist/`，本地调试已关闭合法域名校验。持续开发可运行：

```bash
pnpm --dir miniprogram dev:weapp
```

`TARO_APP_RELEASE_CHANNEL` 支持三种值，构建时分别读取对应地址：

| 通道 | 用途 | API 变量 |
|---|---|---|
| `develop` | 本地开发者工具 | `TARO_APP_API_BASE_URL_DEVELOP` |
| `trial` | 微信体验版/提审前真机 | `TARO_APP_API_BASE_URL_TRIAL` |
| `release` | 正式发布版 | `TARO_APP_API_BASE_URL_RELEASE` |

体验版必须指向生产后端（或与生产等价的提审环境），不能使用 `127.0.0.1`。示例：

```bash
TARO_APP_RELEASE_CHANNEL=trial \
TARO_APP_API_BASE_URL_TRIAL=https://api.example.com \
pnpm build:mp
```

正式版构建：

```bash
TARO_APP_RELEASE_CHANNEL=release \
TARO_APP_API_BASE_URL_RELEASE=https://api.example.com \
pnpm build:mp
```

`trial` 或 `release` 未配置对应 HTTPS 地址时构建会直接失败。可用 `TARO_APP_API_BASE_URL` 做一次性覆盖，但提审构建不建议使用，以免误连环境。API 域名需加入微信后台 request 合法域名，OSS/CDN 结果域名需加入 download 合法域名。

## 5. 媒体安全回调

- `CONTENT_SECURITY=off`：上传和生成图片不请求微信、不写任务表，回调接口旁路；适合本地 UI 调试。
- `CONTENT_SECURITY=wechat`：上传和生成结果调用 `media_check_async`，接口只返回 `pending`，绝不把提交成功当成审核通过。
- 小程序后台“消息推送”的 URL 填 `/api/mp/security/wechat-callback`，Token 与 `WECHAT_MP_CALLBACK_TOKEN` 完全一致，消息格式使用 JSON 明文模式。
- GET 握手会校验 `token/timestamp/nonce` 的 SHA1 签名并原样返回 `echostr`；POST 同样验签。回调为 `risky` 时删除对象存储文件后标记任务，`pass` 只更新状态。

离线验证 pass/risky、签名和 off 旁路：

```bash
pnpm vitest run server/mp/security.test.ts server/mp/wechat-callback.test.ts server/mp/m2-routes.test.ts server/storage.delete.test.ts
```

若手工模拟回调，先用与本地 Token 相同的值计算 SHA1 签名，再向回调 URL 发送：

```json
{"trace_id":"数据库中的 trace_id","result":{"suggest":"risky"}}
```

## 6. 语音真机调试

- 语音按钮使用 `RecorderManager`，格式为 mp3、16kHz、单声道；按住开始，松开后先上传，再把公网音频 URL 交给 ASR。
- 首次使用会请求 `scope.record`。拒绝后再次点击应出现“去设置”引导。
- 开发者工具可检查页面状态和接口桩，但麦克风、后台切换、60 秒自动停止、弱网、相册保存授权必须在真机验证。
- 录音上传和 ASR 不扣积分；修复和每次艺术转换各扣 2 积分，生成失败自动退还并写 recharge 流水。

## 8. M2 自查清单

- [ ] 首页无问候卡，显示右上积分/退出胶囊、品牌区、后端下发主题色的六张卡和页脚。
- [ ] 老摄影大师可拍照/选图，修复与五种艺术风格均有阻塞等待态、结果对比、保存、重试和 AIGC 标识。
- [ ] 暖心文案按“场景 → 对象 → 语气 → 补充说明”推进，补充说明可长按录音并回填文字。
- [ ] 我的页大字模式能放大全站正文/按钮，杀掉并重新打开小程序后仍保持。
- [ ] `CONTENT_SECURITY=wechat` 覆盖任务提交、握手、pass/risky 回调与风险文件删除；`off` 完全旁路。
- [ ] 所有文字不小于 28rpx，主按钮不低于 108rpx，普通点击区域不低于 96rpx；大字模式只增不减。
- [ ] 生产环境未配置微信密钥时登录返回 503；仓库与 Git 历史不含 Secret。

## 9. M3 新模块与积分

M3 上线后首页五个模块可用，只有“AI 摄影师”继续显示“即将上线”：

- AI 故事会：题材推荐免费；生成四页故事结构扣 1 分；四页朗读只在第一页请求时统一扣 2 分；单页配图不额外扣分。
- 生活助手：查菜谱、识花草、健康百科每次各扣 1 分。
- AI 万花筒：正常模型回答每轮扣 1 分；医疗红线输入直接返回就医引导，不调模型、不扣分；模型输出命中药品或剂量红线时自动退还本轮积分。

故事视频合成、订阅消息不属于 M4 提审冲刺范围，本期不实现。

## 10. 万花筒合规验收

小程序使用独立的 `server/mp/chat-persona.ts`，不得复制或引用 H5 万花筒的导购提示词。上线前至少复跑：

```bash
pnpm vitest run server/mp/chat-persona.test.ts server/mp/chat-guard.test.ts server/mp/m3-routes.test.ts
```

人工检查：

- 输入“血压高吃什么药”“帮我看看化验单”时，只出现固定就医引导和免责声明，积分不变。
- 正常询问节气、饮食搭配、运动睡眠或传统文化时，可以多轮回答，回复末尾带“以上内容仅供参考，不构成医疗建议”。
- 页面首次进入只弹一次“我是生活小帮手，健康问题请咨询医生”。
- 每条助手气泡可点击“🔊 读给我听”，TTS 音频通过 `stories-audio/{userId}/` 落存储后播放。

## 13. M4 隐私、探活与日志

- 首次使用相机、相册或麦克风前调用微信官方隐私授权；低版本基础库无该 API 时兼容放行，再由具体权限接口处理。
- “我的 → 关于乐享AI”展示版本号，并可进入《用户协议》《隐私政策》。两份正文带 `TODO（法务定稿）`，未经法务确认不能发布。
- 部署探活使用无鉴权 `GET /api/mp/health`，成功响应为 `{"ok":true,"version":"1.0.0"}`。
- `/api/mp` 请求日志仅含 `userId`、路径、耗时和错误码，不记录请求体、查询参数或用户输入原文。
- 生成接口前端超时为 90 秒且不自动重试；只有 GET 或研发明确标记为幂等的 POST 才最多自动重试一次。

最终人工动作以 `docs/提审准备清单.md` 为准。
