# 总部积分后台：门店同步与发码

## 门店来源与同步

门店和业态以灵芝水铺 AI 内容裂变系统为唯一来源。乐享 AI 不允许手工新增门店，也不设置定时同步。总部管理员登录后台后，在“业态与门店”点击“同步门店信息”；成功提示新增、更新、停用数量及时间。同步失败时原目录不变，应联系技术人员核对来源服务和服务器端 `LINGZHI_INTERNAL_API_KEY`，不要临时伪造门店。

来源删除的门店会在乐享 AI 标为停用，既有批次和兑换记录保留。新批次只能选择同步后仍启用的门店。首次上线应由总部管理员点击一次同步，人工对照来源系统的业态、门店名称和数量。

## 发码对象

- 门店：店长线下采购或总部批准赠送，选择已同步的门店，可创建批量兑换码。
- 总部管理员、公司测试人员、其他试用人员：填写具体接收人，每人一次仅建 1 张赠码；必须填写审批人、原因和审批编号，不能挂靠虚拟门店，也不能走采购用途。

建立批次只记录待确认事项，不生成码。核对线下结算或总部审批后再点击“确认并下载 CSV”。原始兑换码仅此一次可下载，须通过受控渠道交付指定接收人；随后填写交付方式与接收人并确认交付。下载中断时先查看批次状态，不要直接重试；已激活而码丢失，应停用未兑换码后重建批次。总部后台只保留兑换码哈希和审计记录。

## 上线检查

1. 在独立 `*_test` 数据库完成迁移、兑换与同步集成测试；生产迁移前留存数据库备份。
2. 检查服务器侧来源密钥已配置，切勿回显密钥值或将其写入仓库。
3. 部署后检查健康接口、总部后台未登录状态为 401、PM2 单实例，以及原有 `CONTENT_SECURITY=wechat` 配置未回退。
4. 总部管理员手动同步并对照来源门店；用测试账号验证具名赠码的创建、激活、交付和兑换，再向真实人员发放。
