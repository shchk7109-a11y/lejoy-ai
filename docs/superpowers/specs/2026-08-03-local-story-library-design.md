# AI 故事会本机书架与沉浸播放设计

## 目标

在不新增数据库表、不做账号同步的前提下，改善故事题材刷新和朗读体验，并允许用户在当前手机最多保存 6 本故事、删除故事，以及把每本故事导出为 4 张带文字的绘本图片到系统相册。

## 已确认产品决策

- 故事仅保存在当前微信小程序的本地文件空间，不保存到用户账号。
- 换手机、清理微信缓存或删除小程序后，本地故事可能丢失。
- 本地书架最多保存 6 本；第 7 本必须先删除旧故事。
- “下载到本地”定义为：向系统相册写入 4 张“插图＋本页文字＋页码＋AI 生成标识”的绘本图片，不导出 PDF，不下载音频到相册。
- 故事播放使用独立界面，只展示当前页大图、当前页文字、页码及播放控制，不同时展示其他三页。
- “换一批灵感”不设置前端倒计时；按钮始终可见，请求进行期间防重复点击，请求结束后可立即再次刷新。

## 用户流程

### 题材刷新

AI 返回 4 个题材后，页面立即显示暖橙色“换一批灵感”按钮。点击会直接请求下一批题材，刷新不扣积分；请求返回前防止重复点击，结束后可立即再次刷新。

### 生成与播放

故事结构和四页配图仍在原结果页逐页生成。四张配图完成后，用户选择声音并点击朗读，系统逐页准备音频，随后把当前故事草稿写入本地临时状态并进入独立播放器。

播放器显示：

- 当前页插图；
- “第 X / 4 页”；
- 当前页文字；
- 上一页、暂停或继续、下一页；
- 保存故事、下载到相册；
- 返回故事生成结果或书架。

朗读结束后自动进入下一页。手动翻页会停止当前音频并播放目标页；离开播放器时销毁音频实例并恢复屏幕常亮状态。

### 本机书架

本地书架索引只保存轻量元数据：故事 ID、标题、风格、创建时间、四页文字及对应本地文件路径。图片和已生成的朗读音频使用微信小程序永久本地文件；索引使用带版本号的本地存储键。

保存时先下载并持久化所有必需图片，再保存已有音频，最后一次性写入书架索引。任一步失败时删除本次已保存的文件，避免半本故事。音频尚未生成时不因“保存”动作自动扣积分，故事可以只保存文字和图片；以后生成朗读后再补存音频。

保存第 7 本时不覆盖旧故事，提示“书架已满，请先删除一本”，并提供进入书架的操作。删除故事必须二次确认，随后删除其本地图片、音频和索引记录。

### 导出相册

导出使用小程序 Canvas 逐页合成固定比例绘本页：上方为插图，下方为本页文字，底部含页码和“AI 生成内容”标识。四页按顺序逐张调用相册保存接口。首次使用时申请相册权限；拒绝后给出明确说明和打开设置入口。单页失败时显示失败页码，可再次尝试，已经成功写入的页面不自动重复。

## OSS 占用控制

故事图片和朗读音频生成时仍需先落 OSS，不能因为选择“本机书架”就假定 OSS 对象会自动消失。

图片、音频 API 返回的 `fileKey` 会随故事草稿保留。本机保存完成、所有页面已切换到本地路径后，客户端调用资源释放接口。服务端只接受以下当前用户目录：

- `stories/<当前用户ID>/...`
- `stories-audio/<当前用户ID>/...`

释放接口幂等处理多个文件键，不接受任意路径，也不记录故事文字或其他用户输入。未保存就退出的草稿在本地登记待清理文件键，下次进入故事会时补发释放请求；生产 OSS 另建议为两个故事前缀配置短期生命周期，兜底处理卸载小程序后无法补发的对象。

## 数据结构

```ts
type LocalStoryPage = {
  pageNumber: number;
  text: string;
  imagePrompt: string;
  imageUrl?: string;
  imageFileKey?: string;
  audioUrl?: string;
  audioFileKey?: string;
};

type LocalStory = {
  id: string;
  title: string;
  theme: string;
  createdAt: number;
  pages: LocalStoryPage[];
};
```

书架索引最多包含 6 个 `LocalStory`。已保存故事的 `imageUrl`、`audioUrl` 必须为本地永久文件路径；远程 `fileKey` 在释放完成后移除。

## 错误与适老化

- 所有主按钮高度、字号和对比度继续遵守现有适老化令牌。
- 刷新请求中、书架已满、存储不足、相册权限被拒、单页导出失败均不得静默。
- 保存、下载和删除均防重复点击；生成类接口不自动重试，不重复扣积分。
- 下载和清理日志只记录故事 ID、页码、文件数、耗时和状态，不记录故事正文。

## 验收

- “换一批灵感”无倒计时，非请求期间可以直接刷新。
- 播放界面任一时刻只渲染当前页插图，音频结束自动翻页。
- 本机书架可以保存、打开和删除故事，第 7 本保存被阻止。
- 四页绘本图片可顺序保存到系统相册，均包含文字、页码和 AI 标识。
- 资源释放接口拒绝其他用户及非故事前缀文件键。
- 无 schema 变更；生产构建校验、类型检查和完整测试通过。
